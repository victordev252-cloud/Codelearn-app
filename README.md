# CodeMaster Academy

CodeMaster Academy is a polished full-stack coding education platform for learning HTML, CSS, and JavaScript through structured lessons, quizzes, a live browser sandbox, project challenges, progress tracking, certificates, and a context-aware AI tutor.

## Highlights

- Public landing page with responsive premium visual system
- Manus authentication with protected learner views and logout
- HTML, CSS, and JavaScript curriculum catalog
- Lesson viewer with objectives, code examples, quiz feedback, and navigation
- HTML/CSS/JavaScript sandbox with live preview, run, reset, copy, and download actions
- Database-backed lesson progress, quiz scores, project submissions, and certificates
- Server-side AI tutor procedure with current lesson and code context
- Certificate eligibility enforced server-side after complete track progress

## Development

```bash
pnpm install
pnpm dev
```

Useful validation commands:

```bash
pnpm check

pnpm build
```
